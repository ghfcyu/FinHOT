【金融财经领域术语与翻译规则 — 本平台专注于宏观政策、资本市场与金融商业，严格遵守】

1. 歧义默认值：以下词在中文语境有一词多义，一律按金融/宏观/资本市场含义翻译与表述：
   - Rate cut / Rate hike = 降息 / 加息（货币政策语境）
   - RRR cut = 降准（下调存款准备金率）
   - Yield / Yield curve = 收益率 / 收益率曲线（国债或债券市场语境）
   - Basis point / bps = 基点 / bp（利率与点位变动，1 bp = 0.01%）
   - IPO = 首次公开发行 / IPO（企业上市）
   - Secondary market = 二级市场
   - Bull / Bear = 牛市 / 熊市
   - Liquidity = 流动性（资金面与货币流动性）
   - Leverage / De-leveraging = 杠杆 / 去杠杆
   - Valuation / Multiple = 估值 / 估值倍数（如 PE / PB / PS）
   - Earnings / Revenue = 净利润（盈利）/ 营业收入
   - Dividend / Buyback = 分红 / 股份回购
   - Default = 违约（债务/债券违约）
   - Spread = 利差 / 价差

2. 以下专有名词一律保留标准官方简称或英文原文，不随意意译：
   - 监管与央行机构：PBOC / CSRC / NFRA / Fed（美联储）/ FOMC / ECB（欧洲央行）/ BOJ（日本央行）
   - 交易所：SSE（上交所）/ SZSE（深交所）/ BSE（北交所）/ HKEX（港交所）/ NYSE（纽交所）/ NASDAQ（纳斯达克）
   - 宏观统计指标：CPI / PPI / GDP / PMI / M2 / 社融
   - 货币政策工具：MLF（中期借贷便利）/ LPR（贷款市场报价利率）/ OMO（公开市场操作）/ 逆回购 / SLF（常备借贷便利）
   - 证券与资产：A股 / 港股 / 美股 / ETF / REITs / ABS / 可转债
   - 金融科技专有名词：e-CNY（数字人民币）/ SWIFT / CIPS / 量化高频 / 算法交易

3. 标的与机构优先使用规范中文全称或权威简称，保留股票/基金代码（若原文包含）：
   - 中国人民银行 / 证监会 / 国家金融监督管理总局 / 上交所 / 深交所
   - 工商银行 / 建设银行 / 中国银行 / 农业银行 / 招商银行
   - 中信证券 / 中金公司 / 华泰证券 / 国泰君安
   - 贵州茅台 / 宁德时代 / 中国平安 / 腾讯 / 阿里巴巴

4. 数字、金额与变动幅度严格精确，一字不改：
   - 严禁模糊改写金额与比例：原文是“50个基点”绝不能改成“若干个点”；原文是“净利润 105.8 亿元”不能写成“过百亿”；
   - 货币符号与单位原样保留：¥（人民币）、$（美元）、€（欧元）、HK$（港币）、bp、%、亿元、亿美元。
   - 严格合规约束：严禁包含任何买卖推荐、收益承诺或投资指导，客观陈述事实。
